# LinkedTaiwanArtists
A collection of information about the art in Taiwan for the Information Visualization Project

##What can you find here?

- A data set from the Linked Taiwan Artists SPARQL endpoint: https://linkedart.ascdc.tw/index.php?lang=en_US.utf8
- A set of csv data tables that we extracted from there and we have been using to create visual charts
- A Jupyter notebook including the coding functions and queries we have been performed, with comments and annotations: TAI.ipnb
- A website as our project presentation in the CCP folder: https://lelax.github.io/LinkedTaiwanArtists/CCP/index.html
